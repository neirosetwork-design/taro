# Карта дня — классическое таро Райдера — Уайта

Что это: страница «задай вопрос → вытяни карту дня». Короткое значение сразу, полное — по кнопке.
Ниже: голосовой разбор вопроса от эксперта (заявка уходит в Telegram) и кнопка «Написать» на полный расклад.

## Как открыть
Открыть `index.html` в браузере. Зависимости не нужны — чистые HTML/CSS/JS.

## Где менять
- `cards-data.js` — тексты всех 78 карт: `ru` (название), `short` (короткое значение), `full` (полное), `img`.
- `index.html`, блок «НАСТРОЙКИ» внизу: `expertName` (имя), `expertRole` (направление), `expertTg` (username эксперта в Telegram, без @).
- Картинки — папка `cards/` (78 файлов из открытого набора tarotcardapi, лицензия MIT).

## Заявки и статистика
- Кнопка «Отправить заявку в Telegram» открывает чат с экспертом (`expertTg`) с готовым сообщением: вопрос, карта дня, имя и контакт. Эксперт отвечает голосовым на указанный контакт.
- События для счётчика в `<head>`: `page_open`, `card_draw`, `full_open`, `voice_open`, `lead_submit`, `full_reading_click`.
- Следующий шаг (по желанию): Telegram-бот со статусами заявок и ежедневной сводкой.

## Проверка
Открыть страницу → написать вопрос → «Получить ответ от Таро» → карта и короткое значение → «Полное значение карты» → форма голосового разбора → «Отправить заявку в Telegram» (откроется чат с готовым сообщением).
В `cards-data.js` должно быть 78 записей; пути картинок — `cards/xxx.jpeg`.
